# Portfolio

Le site personnel d'**Oumar Ahmat SOULEYMANE**, étudiant en L3 Informatique à l'Université Claude Bernard Lyon 1 : mes projets, ma méthode de travail, mes compétences et mon parcours.

## Organisation

| Dossier ou fichier | Rôle |
| --- | --- |
| `public/index.html` | Le contenu de la page |
| `public/css/style.css` | L'apparence : couleurs, polices, mise en page, thème clair et sombre |
| `public/js/main.js` | Les parties interactives : statut en direct du robot Vélo'v, jeu de Nim, thème, copie de l'e-mail |
| `public/img/` | La photo et l'icône de l'onglet |
| `public/cv.pdf` | Mon CV |

Seul le dossier `public/` est mis en ligne. Le reste sert à travailler sur le site.

## Choix techniques

- **HTML, CSS et JavaScript, sans framework** : la page est légère, rapide, et chaque ligne se lit sans outil.
- **Statut en direct** : la page demande à l'API publique de GitHub la date du dernier relevé de mon robot [Vélo'v](https://github.com/S-oumar/velo-v-lyon).
